# CTA Train Interactive Simulator

A C# Walking Simulator built in Unity featuring character dialogue and dynamic pixel art.

## Technical Highlights
* **Language & Framework:** C#, .NET Framework, Unity
* **Architecture:** Object-Oriented Programming (OOP), event-driven UI triggers, and decoupled interaction scripts

## Project Overview
This project simulates an interactive environment aboard Chicago Transit Authority (CTA) trains. Players can explore train cars and interact with non-playable characters (NPCs) through a dynamic text-rendering pipeline.

## Features
* Interactive dialogue system powered by C# event handlers.
* Modular script architecture designed for scalable feature expansion.
